# 墨灵正式上线主规划 v1.0

更新时间：2026-07-25

## 1. 冻结目标

墨灵不再按“长期打磨中的 Demo”管理，而是直接进入正式上线工程。

最终目标不是生成一个可演示 APK，也不是用用户验证代替开发，而是完成以下闭环：

1. Android 客户端可稳定安装、远程使用、更新；
2. DeepSeek 后端可控调用、可观测、可计费；
3. “老g”人格与每个用户的私有记忆形成产品核心；
4. Google Play 与华为 AppGallery 至少完成实际提交，满足条件后进入正式分发；
5. 首个正式版具备本地笔记、基础云同步、免费额度与收费升级路径；
6. 上线后持续迭代，而不是在上线前追求功能完备。

## 2. 产品本质

墨灵不是聊天软件，也不是把 ChatGPT 套进手写界面。

它是一款 Android 平板优先的 AI 手写笔记本：用户先在纸面上写，系统理解后，墨灵像一本有长期记忆、有判断、熟悉用户的笔记本一样以墨迹回应。

核心链路必须保持：

```text
用户笔迹
→ 本地手写识别
→ 本地保存原始笔迹和识别结果
→ 服务端加载人格、用户记忆和最近上下文
→ DeepSeek 生成结构化回应
→ 客户端以墨迹浮现
→ 本地保存回应并等待同步
```

无论识别、网络、模型或同步是否失败，原始笔迹都不得丢失。

## 3. 四项架构决策

### 3.1 模型

默认模型改为 DeepSeek，不再以 OpenAI 为生产默认后端。

- 日常回应：`deepseek-v4-flash`，关闭思考模式；
- 深度回应：`deepseek-v4-pro`，按需启用思考模式；
- 业务层通过 `ModelProvider` 适配器调用，不让产品代码绑定某个 SDK；
- 已于 2026-07-24 弃用的 `deepseek-chat` 与 `deepseek-reasoner` 不得写入新代码。

### 3.2 人格

“像老g”不是一句风格要求，而是独立的产品系统：

- 老g风格核心：第一性原理、熟悉上下文、敢判断、温暖可靠、不油腻、不机械追问；
- 用户私有记忆：身份、关系、目标、项目、已冻结决策、偏好、禁忌、最近状态；
- 运行时上下文：当前页面、最近几轮、当前任务；
- 安全层：高风险内容覆盖普通人格。

风格层可以服务所有用户；赵焱阳的私人记忆只能进入其个人账户的私有 memory pack，绝不能进入公共安装包或其他用户上下文。

### 3.3 上线

上线工程和商店流程并行推进：

- 代码侧直接完成生产后端、签名、AAB/APK、隐私与支付预留；
- Google Play 先开内部测试，并立即满足可能存在的封闭测试要求；
- 华为 AppGallery 全球版同步准备和提交；
- 中国大陆版本单独处理 APP 备案、境内网络资源、隐私与数据跨境边界，不阻塞全球版本。

### 3.4 数据

第一版实行本地优先：

- 原始笔迹、笔记页面、AI 回应先落本地数据库；
- 服务端只接收生成回答所需的最小文本；
- 默认不上传纸面截图；
- 云同步只同步用户明确保存的数据；
- 服务器日志不记录笔记正文、recentContext 或完整 AI 回应。

## 4. 版本路线

### v0.8｜远程可用工程版

必须完成：

- 全新 clone 可构建；
- DeepSeek V4 调用适配；
- 生产 HTTPS 后端；
- Debug/Release 环境分离；
- 设备或账户鉴权；
- 限流、预算和日志脱敏；
- 本地持久化；
- 请求状态机与失败恢复；
- 签名 APK。

交付物必须包含可安装包和远程后端，审计报告不能作为唯一成果。

### v0.9｜商店审核候选版

必须完成：

- AAB 与 APK 构建；
- 正式图标、名称、截图和商店文案；
- 隐私政策、用户协议、支持页面、删除账户/数据说明；
- Crash 监控；
- 版本更新机制；
- Google Play 内部/封闭测试；
- 华为 AppGallery 提交材料；
- 基础账号体系和加密同步可用。

### v1.0｜首个正式上架版

功能边界：

- 纸面书写；
- 中文手写识别；
- 老g式 AI 回应；
- 本地笔记保存；
- 账户与跨设备同步；
- 基础纸张、字体和墨色设置；
- 免费额度；
- Pro 权益入口可以存在，但收费功能可按商店审核进度分阶段开放。

明确不要求：

- iOS；
- Web 完整编辑器；
- 复杂知识库；
- 社交；
- 多人协作；
- 大量模板；
- 全 Android 设备无差别兼容。

### v1.1｜同步和可持续使用

- 增量同步；
- 冲突解决；
- 导出；
- 历史记忆整理；
- 账户注销与数据删除完整闭环；
- 华为、Google 订单权益统一。

### v1.2｜收费与深度模式

- 月度/年度订阅；
- Deep 模式；
- 更多 AI 配额；
- 高级纸张、字体、导出；
- 更完整的长期记忆；
- 服务端权益账本和订单校验。

## 5. 开发工作流

### M0｜真实基线 + 立即改造

Codex 恢复后先做全新 clone、构建、测试和密钥扫描，但不得停在报告阶段。同一轮必须完成至少一项代码改造，优先是 DeepSeek 适配与环境配置。

### M1｜DeepSeek 后端

- 新增供应商适配层；
- 使用 OpenAI-compatible Chat Completions；
- JSON Output；
- `max_tokens`；
- `user_id` 匿名隔离；
- 一次受控重试；
- 错误映射；
- Token 与人民币成本统计；
- Flash/Pro 路由。

### M2｜老g人格与记忆

- Persona Prompt v1；
- 个人记忆 schema；
- 赵焱阳私有 seed memory；
- 公开用户空白 memory pack；
- 记忆提取、写入、过期和删除规则；
- 30 组回归样本；
- prompt 版本与回滚。

### M3｜客户端生产化

- BuildConfig 环境；
- Release 禁止明文 HTTP；
- 本地数据库；
- requestId、防重复提交和 stale response 防护；
- ML Kit 模型状态检查；
- 无 GMS 设备兼容提示；
- 签名与版本号；
- Crash 监控。

### M4｜多端同步

首版同步不是“把所有笔迹实时传云端”，而是可靠的账号数据同步：

- 本地为即时真相；
- 云端保存加密后的页面数据和结构化记忆；
- 每条记录有 `id`、`updated_at`、`device_id`、`revision`；
- 增量上传与拉取；
- 冲突先保留双版本，不静默覆盖；
- 未登录用户可以完全本地使用；
- 登录后主动开启同步。

### M5｜双商店发布

- 建立官网支持页和隐私链接；
- 准备截图、短描述、完整介绍、更新说明；
- Google Play 内部测试立即启用；
- 华为 AppGallery 全球版同步提交；
- 根据账号与地区要求完成测试、身份验证、APP 备案和审核整改；
- 商店流程中的等待时间用于继续修复，不停工。

### M6｜收费

- 免费层先可用；
- 权益按账户统一；
- Google Play Billing 与华为 IAP 只负责收款和订单；
- 服务端验证订单并写入统一 entitlement；
- 不向用户售卖“Token”；
- 用户购买的是持续使用、深度回应、同步和高级功能。

## 6. 上线优先级

### P0：直接阻止上线

- 局域网硬编码后端；
- 明文 HTTP；
- 无鉴权与无限调用；
- 用户正文进入日志；
- 图片落盘；
- 无本地保存；
- 请求失败丢笔迹；
- 无签名与版本构建；
- 无隐私政策。

### P1：首发应有

- 基础账号；
- 增量同步；
- Crash 监控；
- 反馈入口；
- 商店素材；
- 免费额度；
- 设备兼容提示。

### P2：上架后迭代

- 高级订阅；
- 深度模式；
- 完整导出；
- iOS；
- Web；
- 更多识别引擎；
- 多模态理解。

## 7. 上线完成定义

墨灵只有同时满足以下条件，才算从原型升级为正式上线产品：

1. 至少一个公开应用商店已经正式可下载，另一个已提交或处于明确审核轨道；
2. 生产后端可用，密钥、限流、预算和日志边界成立；
3. 用户笔记本地可靠保存；
4. 跨设备同步至少支持账户数据和文本/回应；
5. 老g人格经过回归测试，不再依赖单一长 Prompt 的偶然发挥；
6. 具备收费架构，即使首发阶段暂未开启收费；
7. 上线后监控、版本迭代和回滚路径明确。

## 8. Codex 首轮启动要求

Codex 额度恢复后，直接读取本目录全部文件和根目录 `AGENTS.md`，然后执行：

1. 冻结真实构建状态；
2. 立即实现 DeepSeek V4 适配；
3. 完成环境分离、日志脱敏和最小后端测试；
4. 产出 v0.8 可安装构建与部署清单；
5. 不重新讨论是否上线，不用“还需验证”替代代码交付。
